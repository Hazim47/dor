# Dor - موقع المطعم

## التشغيل
```
npm install
npm run dev
```
افتح http://localhost:3000

## تعديل المنيو والأسعار
ملف `lib/menu.ts`

## تعديل رقم الواتساب والروابط
ملف `lib/config.ts`

## الصور
ضع كل صورة داخل `public/images/` بنفس الاسم المكتوب بالأسفل (jpg).
إذا ما وُجدت الصورة بيظهر مكانها مربع فيه اسم الملف المطلوب.
